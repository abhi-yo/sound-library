---
title: CLI Reference
description: Command-line interface for scaffolding procedural sound functions into your project.
---

The CLI downloads standalone TypeScript sound definitions directly into your codebase.

```bash
npx sound-library [command] [options]
```

---

## Commands

### `list`

Lists all 45 procedural sound effects organized by interaction category.

```bash
npx sound-library list
```

---

### `add`

Scaffolds specified sound functions into `components/sonix/`.

```bash
npx sound-library add tap snap chime whoosh
```

<Callout type="info">
  Each generated file is self-contained and imports no external libraries. Import generated sounds from `@/components/sonix` in your client components.
</Callout>

**sound-library** (Sound Bits) is a zero-runtime-dependency package of procedural micro UX sounds. Everything is synthesized in the browser with the Web Audio API — no audio files, no CDN assets.

```bash
npm i sound-library
```

Then:

```tsx
'use client';

import { playSound } from 'sound-library';
import { SoundButton } from 'sound-library/react';

export function Example() {
  return (
    <>
      <button type="button" onClick={() => playSound('tap')}>
        Tap
      </button>
      <SoundButton sound="chime">Notify</SoundButton>
    </>
  );
}
```

Call audio only from user gestures (`click` / `pointerdown` / `keydown`). Playback auto-mutes when `prefers-reduced-motion: reduce`.

## Core API

| Export | From | What it does |
| --- | --- | --- |
| `playSound(name, options?)` | `sound-library` | Play a named procedural sound |
| `playTap`, `playChime`, … | `sound-library` | Per-sound convenience wrappers |
| `setSoundEnabled` / `isSoundEnabled` | `sound-library` | Global mute |
| `SOUND_NAMES` / `SOUNDS_METADATA` | `sound-library` | Typed ids + titles / categories |
| `SoundButton` / `useSound` | `sound-library/react` | React helpers (`'use client'` in Next.js) |

```ts
import { playSound, setSoundEnabled, SOUND_NAMES } from 'sound-library';

playSound('pop', { volume: 0.6 });
setSoundEnabled(false);
```

Prefer the package over hand-rolled Web Audio unless you intentionally want a custom synthesis.

## Patterns

**Button / confirm**

```tsx
<button type="button" onClick={() => playSound('button-click')}>
  Save
</button>
```

**Toggle**

```tsx
<button
  type="button"
  onClick={() => playSound(on ? 'toggle-off' : 'toggle-on')}
>
  Toggle
</button>
```

**Toast / success**

```tsx
playSound('chime');
```

**Scaffold without a runtime dependency**

```bash
npx sound-library add tap chime pop
```

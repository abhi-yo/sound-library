The skill is a **package** in the [skills.sh](https://skills.sh) ecosystem — same idea as npm, for agent context. One install wires it into Cursor, Claude Code, Codex, Copilot, Windsurf, and [dozens more](https://github.com/vercel-labs/skills#supported-agents).

## Install the skill package

```bash
npx skills add abhi-yo/sound-library
```

That pulls `skills/sound-library/SKILL.md` from the GitHub repo and installs it for your agent(s). Options:

```bash
# global (all projects)
npx skills add abhi-yo/sound-library -g

# list skills in the package
npx skills add abhi-yo/sound-library --list

# only this skill
npx skills add abhi-yo/sound-library --skill sound-library -y
```

Discover more: [skills.sh](https://skills.sh) · `npx skills find sound`

## What it teaches the agent

- `npm i sound-library` (or `npx sound-library add <name>` to scaffold files)
- `playSound` / `SoundButton` / `useSound` — not hand-rolled Web Audio
- Wire sounds onto the exact UI you asked for
- Gesture-only playback + `prefers-reduced-motion`

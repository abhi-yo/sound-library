title: Installation

## Package

```bash
npm i sound-library
# pnpm add sound-library
# yarn add sound-library
# bun add sound-library
```

```ts
import { playSound } from 'sound-library';

playSound('tap');
```

### React

Optional peer: `react >= 18`.

```tsx
'use client';

import { playSound } from 'sound-library';
import { SoundButton, useSound } from 'sound-library/react';

<SoundButton sound="chime">Notify</SoundButton>

const { play } = useSound('tap');
<button type="button" onClick={() => play()}>Go</button>
```

Next.js App Router: keep these imports in `'use client'` files only.

---

## CLI scaffold (no runtime dep)

If you want standalone files instead of importing the package:

```bash
npx sound-library list
npx sound-library add tap chime
npx sound-library add all
```

Details in [CLI Reference](/docs/cli).

---

## Requirements

- Modern browser with Web Audio API
- Trigger from a user gesture (autoplay policies)
- Auto-mutes when `prefers-reduced-motion: reduce`

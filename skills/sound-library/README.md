# sound-library skill

Agent skill for [sound-library](https://www.npmjs.com/package/sound-library) (Sound Bits).

## Install

```bash
npx skills add abhi-yo/sound-library
```

Or install only this skill:

```bash
npx skills add abhi-yo/sound-library --skill sound-library
```

Browse on [skills.sh](https://skills.sh) after installs start landing.
